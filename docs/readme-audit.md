## 记录方式

题目明确要求在 README 记录实际投入与取舍，以及技术、启动、配置、接口、演示、身份、完成程度、部署回滚、AI 工作流和来源。它没有要求把每一次命令和全部对话写入 README。

本项目按用户约定每阶段更新：README 提供阶段成果、验证、取舍与投入汇总；开发日志提供过程证据；专项文档提供操作和验收步骤。反馈和 CI 结果继续补记，未完成阶段不填成已完成，Git 由用户提交和推送。
